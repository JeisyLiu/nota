Add a Windows desktop target so the phone UI can be recorded without an emulator

The deliverable needs a portrait mobile screen. The Android build already
exists but capturing it needs a device or an emulator; instead the same Flutter
app now also targets Windows, with the runner window sized to a phone's logical
viewport (390x844, iPhone 14) instead of the 1280x720 desktop default.

The layout is width-driven, so what the window draws is what the Android build
draws -- only the frame differs. Win32Window already scales by DPI, so the 390
figure stays logical across display scales. record_windows_plugin.dll ships in
the bundle, so hold-to-talk works here too, against the same backend.

Built with `flutter build windows --release`: 28.9 MB versus 106.9 MB debug,
and no Dart VM service, which is what you want in a recording. analyze is clean
and all 11 tests still pass.

The screenshot in docs/img/app-portrait.png is from that release build running
against the live backend.
