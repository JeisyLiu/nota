# 3 分钟录屏脚本

两个端：**手机形态的 App**（Windows 版竖屏窗口）和**后台管理台**（`http://127.0.0.1:8787`）。
App 讲"用户怎么用"，后台讲"账号、用量、管理"，Agent 轨迹放在 `/trace` 作可选补充。

## 开录前（不录）

```powershell
cd F:\projects\dsh-sandbox\AIAppDeveloper\nota
.\run.ps1                      # 后端：真实 DeepSeek + 本地 whisper，首次会种 6 个账号
# 另开一个窗口
cd app\nota_app\build\windows\x64\runner\Release
.\nota_app.exe                 # 竖屏 390x844
```

浏览器打开 `http://127.0.0.1:8787`，窗口拉到约 1440x900。

确认：登录页能打开、演示账号按钮可见、App 额度是 `0 / 10`。

---

## 第一段 · App：一句话变成待办（0:00–0:50）

**0:00** 左侧竖屏 App，右侧登录页，静 3 秒。

> "这是 Nota。左边手机界面说一句话就记下来，右边是它的后台管理台。"

**0:10** App 底部输入框输入：

```
明天下午三点提醒我给张总发报价单
```

点发送。自动跳详情页，指出状态**转写中 → 整理中 → 已完成**、摘要、待办与提醒各一条（明天 15:00）。

**0:30** 下滑到 **Agent Trace**：

> "每次工具调用都在这里，参数是完整 JSON，落库可审计。"

**0:45** 点一下待办复选框，划掉。

---

## 第二段 · App：边说边出字（0:50–1:30）

**0:50** 返回主页，**按住**底部圆钮，正常语速说：

```
下周三上午十点跟设计团队评审新版原型
```

> 说话过程中按钮上方逐段出现文字 —— 本地 whisper 边收边转。

**1:15** 说完再松手，等约 10 秒，详情页显示下周三（11-18）10:00 的待办。

> "转写用本地 whisper，不花钱不出网；只有整理那步才调大模型。"

---

## 第三段 · 后台：登录与全局（1:30–2:25）

**1:30** 切到浏览器，点登录页的 **admin · 管理员** 演示按钮（自动填账密），点登录。

**1:38** 进入 **全局概览**，从上往下说：

> "6 个账号、144 条记录、92% 任务成功率、Token 消耗、平均延迟、10 个待审批。下面是近 14 天的新增记录和额度消耗趋势，右边是任务状态分布和工具调用 Top。"

**1:55** 左侧点 **用户管理**：

> "每个账号的套餐、记录数、今日用量、成功率、最后活跃。套餐可以直接改。"

把 `zhangwei` 的套餐从 Free 切成 Pro，出现提示即可。

**2:05** 点 `zhangwei` 那行的 **详情**：进入单用户档案（套餐、今日用量、记录数、成功率、14 天趋势、该用户的待办与提醒）。

在右侧「代用户添加」里填一条待办，例如 `给张总回电话`，时间 `2026-11-12 15:00`，点 **添加待办**。

> "客服在电话里帮用户补一条任务，不用登进对方账号——时间会按用户所在时区落库。"

下面「该用户的待办」立刻多出这一条。

**2:15** 点 **任务管理**：选状态筛选，指出失败任务上的 **重试**、运行中任务上的 **取消**。

**2:22** 点 **待审批**：展示不可逆操作的参数与超时说明。

> "日历、发邮件这类不可逆操作不会自己执行，挂起等用户确认，超时视为拒绝。"

## 第四段 · 后台：普通用户视角（2:25–2:55）

**2:25** 右下 **退出登录**，这次点 `zhangwei · 张伟` 登录。

**2:32** 个人 **概览**：

> "同一个后台，普通用户只看得到自己：今日剩余 8/10、近 14 天记录 30 条、成功率 93%、11 个待办未完成。"

**2:45** 点 **调用记录**：时间、来源（语音/文字）、内容、状态、错误原因。

**2:52** 点 **个人信息**：账号资料 + 改密码（改密码会让其它设备下线）。

## 可选：Agent 轨迹页（不进正片）

## 录制时的注意

| 现象 | 处理 |
|---|---|
| 第一次按住说话，文字要等约 20 秒 | 流式模型冷加载，**先随便录一条**再正式录 |
| 说完立刻松手，最后一个字丢了 | 说完停半秒再松手 |
| 登录后看不到"全局概览" | 说明用的是普通用户，退出后用 `admin` 登录 |
| 用户管理里标题显示 8 个账号但表格只有 6 行 | 旧库遗留的无用户名账号；重启后端后按"可登录账号"口径统计 |
| 改套餐后没变化 | 刷新页面，或看用户自己登录后的套餐标签 |
| App 额度到 0 | 控制台右上"用户"换名字，或删 `data\nota.db` 重启（会重新种账号） |

## 一镜到底 vs 分段

建议**分三段录**：App、后台管理员、后台普通用户。最后剪在一起，比来回切窗口干净。
