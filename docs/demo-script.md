# 3 分钟录屏脚本

两个端都要出现：**手机形态的 App**（Windows 版竖屏窗口）和**网页控制台**（`http://127.0.0.1:8787`）。
App 讲"用户怎么用"，控制台讲"里面发生了什么"，后者是 Agent 可审计的证据。

## 开录前（不录）

```powershell
cd F:\projects\dsh-sandbox\AIAppDeveloper\nota
.\run.ps1                      # 后端：真实 DeepSeek + 本地 whisper
# 另开一个窗口
cd app\nota_app\build\windows\x64\runner\Release
.\nota_app.exe                 # 竖屏 390x844
```

浏览器打开 `http://127.0.0.1:8787`，窗口拉到大约 1440x900。

确认两件事：App 顶部额度是 `0 / 10`，控制台右上角标签是 `OPENAI · DEEPSEEK-CHAT`（不是 `demo`）。
如果额度不是 0，说明之前的测试数据还在，可以先跑一次"问历史"确认检索有内容，不影响录制。

---

## 第一段 · App：一句话变成待办（0:00–0:55）

**0:00** 让竖屏 App 停在屏幕左侧，浏览器控制台在右侧，先静 3 秒。

> "这是 Nota。左边的手机界面说一句话就记下来，右边的控制台显示它在后台做了什么。"

**0:10** 在 App 底部输入框输入：

```
明天下午三点提醒我给张总发报价单
```

点发送。

**0:15** 自动跳到详情页。依次指出：状态**转写中 → 整理中 → 已完成**（会看到它在变），
摘要卡片，下面**待办**和**提醒**各一条，时间都是明天 15:00。

**0:30** 往下滑到 **Agent Trace**：

> "每一次工具调用都在这里，`set_reminder` 和 `create_todo` 的参数是完整 JSON。"

**0:45** 点一下待办前面的复选框，让它划掉。

---

## 第二段 · App：边说边出字（0:55–1:45）

**0:55** 返回主页。**按住**底部圆形按钮不放，正常语速说：

```
下周三上午十点跟设计团队评审新版原型
```

> 关键：**说话的时候**按钮上方就会逐段冒出文字。这是本地 whisper 边收边转，
> 说"下周三"的时候前面几个字已经显示出来了。

**1:20** 说完再松手。等约 10 秒，详情页显示：下周三（11-18）10:00，一条待办。

> "转写用本地 whisper，不花钱、不出网；只有整理成待办那一步才调用大模型。"

**1:35** 回到主页，指一下额度条：数字比开始时增加了 —— 每次消耗 1 次。

---

## 第三段 · App：随时停止（1:45–2:05）

**1:45** 再按住说一句：

```
这周五晚上八点提醒我抢演唱会门票
```

松手后**立刻**点右上角**停止**。

**1:55** 状态变成**已停止**，摘要显示"已停止，本次额度已退回"，额度数字退回去了。

> "取消不是失败：不重试、不报错，额度退回。后台在阶段之间检查，不会为空转的活儿付费。"

---

## 第四段 · 网页控制台：可审计的证据（2:05–2:50）

**2:05** 切到浏览器（最大化）。三段：说一句 / 整理结果 / Agent Trace。

**2:10** 在输入框输入：

```
把下周三上午十点的评审加到我的日历里
```

点发送。

**2:25** 右边 trace 出现 `create_calendar_event` 调用，中间出现**需要你确认**的黄色卡片，
里面是完整参数（`title`、`start_at`、`duration_minutes`）。

> "日历属于不可逆操作，Agent 不会自己执行，而是挂起等用户确认。这是刻意设计的闸门。"

**2:35** 点**确认执行**。卡片消失，trace 里出现执行结果。

**2:40** 在"问历史"里输入：

```
上次给张总的报价是多少
```

回车。回答带 `[note:...]` 引用。

> "它检索历史记录回答，并标出出处；没有依据就说没有记录，不编造。"

---

## 收尾（2:50–3:00）

回 App 或指一下控制台顶部：

> "整条链路：语音 → 本地转写 → Agent 工具调用 → 待办和提醒。额度按天计，用光返回 429。
> 代码在仓库里，`python -m pytest` 和 `scripts/verify.ps1` 可以复现。"

## 录制时的注意

| 现象 | 处理 |
|---|---|
| 第一次按住说话，文字要等 20 秒才出 | 模型在冷加载。**先随便录一条再正式录**，之后就快了 |
| 说完立刻松手，最后一个字丢了 | 说完停半秒再松手 |
| 转写出来是繁体字 | 预览已强制简体；若仍出现，说明用的是旧后端，重启 `run.ps1` |
| 控制台右侧 trace 太快滚到底 | 正常，它跟随最新一步；录屏时往上滚一下看全貌 |
| 详情页一直"转写中"不结束 | 后端在跑 whisper，等 10–15 秒；超过 30 秒检查后端窗口有没有报错 |
| 额度到 0 | 换 `用户` 输入框成别的名字，或删 `data\nota.db` 重启 |

## 一镜到底 vs 分段

建议**分两段录**：App 一段（竖屏窗口 + 出字幕），控制台一段（全屏）。
剪在一起比来回切屏干净，而且 App 那段窗口小，全屏录会有一圈空白。
